# Todolist-backend
---

API para gerenciar tarefas (CRUD) backend

---

## Tecnologias
  
- **Spring Boot** 
- **Spring MVC**
- **Spring Data JPA**
- **SpringDoc OpenAPI**
- **Oracle Data Base**
- **H2 Memory DB**

## Práticas adotadas

- SOLID
- API REST
- Consultas com Spring Data JPA
- Injeção de Dependências
- Tratamento de respostas de erro
- Geração automática do Swagger com a OpenAPI
